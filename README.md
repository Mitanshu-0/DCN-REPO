# Data Communication and Networking Laboratory — Report-based source

Code from the supplied DCN_EXP_1 through DCN_EXP_4 DOCX laboratory reports. The original code is preserved, including possible errors, hard-coded host IPs, hard-coded filesystem paths, and file name mismatches. No changes or simplifications have been deliberately made to the selectable report code.

- Practical 1: TCL, AWK, shell code copied from selectable report paragraphs.
- Practical 2: bus/star/ring/mesh TCL, AWK, shell copied from selectable report paragraphs.
- Practical 3: TCL **manually transcribed** from screenshots in the report. Check against the original images if character-perfect fidelity matters.
- Practical 4 part 1: Python client/server manually transcribed from screenshots. The closing statement in `client.py` is below the screenshot crop and has NOT been invented, so the file contains only the visible lines. Part 2 chat source is **incomplete in the report**: only visible excerpts in a TXT, not fabricated programs. Part 3 file transfer Python copied directly from the selectable report text.
- Practical 5–7: original uploaded Packet Tracer `.pkt` files, byte-for-byte unchanged.
- Practical 8: no Packet Tracer project uploaded; omitted.

The code has NOT been modified to make it run and simulations have not been tested. Some report scripts contain incorrect or hard-coded paths and mismatched file names. If exact source fidelity is the priority, use the original text and screenshots as final authority.
